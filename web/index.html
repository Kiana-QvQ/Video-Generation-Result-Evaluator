HOW IT READS

五项先各自换算为 0—1，再按权重合成总分；缺少某项时只按已覆盖的权重计算，并标记为部分覆盖。GT 必须与结果逐帧对应。

VBENCH / OPTIONAL AUTO EVAL VBench 不是第六个加权项

VBench 是独立的自动视频评测框架，本网页接入 aesthetic_quality，输出 0—1 分；CUDA/VBench 可用时作为第 5 项“美学质量”，不额外计入总分。

01 / 35% 角色一致性 ArcFace

逐帧比较参考人脸与结果人脸，关注相似度和稳定性。

02 / 15% 质感和细节 MANIQA / MUSIQ

有 GT 比较像素与感知差异；无 GT 评估清晰度和细节。

03 / 15% 表情准确 ViCLIP / CLIP ETVA VLM Judge / Qwen2-VL-2B AWQ

按 Prompt 或参考视频判断结果的表情与动作是否对齐。

04 / 25% 时间稳定性 Face Mesh / Farneback

检测帧间光流、warping 误差和人脸关键点抖动。

05 / 10% 美学质量 VBench aesthetic_quality

评估画面的审美、清晰度、曝光和色彩表现。
