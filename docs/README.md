# Documentation Index

The documentation is grouped by purpose:

- `01_algorithm`: Wang Xing algorithms, V5 specifications, papers, AU and forensics.
- `02_data_evaluation`: Dataset policy, evaluation protocols and data strategy.
- `03_deployment`: HTTP/gRPC deployment, security, assets and public showcase.
- `04_project_records`: Work logs, evidence lists and project classification.
- `05_leadership`: Short reports and leadership-facing metric definitions.
- `99_assets`: Evaluation images and example manifests.

The online web service remains on the legacy V3/Wang Xing path by default.
