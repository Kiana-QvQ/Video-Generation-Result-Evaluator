# 仓库内容与数据策略

本仓库 **GitHub 只保留代码、文档与小配置**。下列内容仅保存在本地/内网，**不上传**：

| 不上传 | 说明 |
|--------|------|
| `data/` | 真拍/Seedance 视频、全量 AU、音频等数据集 |
| `outputs/` | 训练产物、指标 JSON、特征缓存、本地 `.pt` |
| `model_cache/` | Qwen 等大模型缓存 |
| `human_review/data/` | 人审运行时数据集与数据库 |
| `*.pt` / `*.pth` / 视频 / `*.pcm` 等 | 权重与媒体 |
| `docs/领导汇报_真伪检测指标口径.md` | 内部汇报口径，仅本地使用 |

本地需要自行准备：

- 数据集目录结构见项目既有约定（`data/MD_CL`、`data/WangXing_Seedance`、`data/au/...`）
- 留出协议示例（仅路径清单模板）：[`examples/holdout_split.example.json`](examples/holdout_split.example.json)
- 王兴视频 `.pt` 训练后默认在：`outputs/vedio_pred/models/`（被 ignore）

克隆本仓库后：安装依赖 → 按内网说明放置 `data/` 与权重 → 再跑 `scripts/` / `wangxing_project/`。
