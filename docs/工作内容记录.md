## 当前阶段工作概括

- 5月：完成光影/光源项目的 LoRA 训练流程和光照控制数据准备。
- 6月：完成表情视频标签整理和 LTX2.3 光照控制数据准备。
- 7月：完成光影 LoRA/重新打光实验、表情数据集构建和评估器 Prompt 对照测试。
- 8月：完成视频评估器、Wang Xing AU/身份专项、真人/Seedance 取证和人工复核系统。

## 主要结果

- 表情数据集：`627` 个源视频，切分为 `3135` 个片段。
- 评估器：`407` 个 Web 任务目录，`400` 份可解析评估结果。
- 评估输出：`987` 个 CSV、`941` 个 JSON、`452` 个 MP4。
- Wang Xing 表情画像：`648` 个样本。
- 真人/Seedance 取证：`100` 条留出数据，无泄漏学习融合准确率 `96%`。
- 光影实验：`7` 个 LTX2.3 对照视频、`2` 个 LightCtrl 视频、`36` 张审查图片。
