# 全量硬判优化：训练与评估（由你本地执行）

目标：取消「不确定区间」作为主指标口径，改为 **每条样本都必须判真/生成**，并通过：

1. 质量过滤重建 forensics 画像（丢掉低 landmark / 低姿态归一化比例的 AU）
2. 王兴 `wangxing_source` + forensics 运动证据融合
3. 非 holdout 重校准
4. holdout 上报告 **生成召回率** 与 **整体准确率**（coverage=100%）

> 不确定区间相关代码仍保留在 `authenticity_decision.py`，但本流水线评估默认 `allow_uncertain=False`。

## 你需要跑的三步

在仓库根目录、建议使用 `.venv`：

### 1）重建质量过滤画像（训练侧）

```powershell
.\.venv\Scripts\python.exe scripts\run_hard_detection_pipeline.py build-profile `
  --min-landmark-ratio 0.45 `
  --min-pose-ratio 0.35 `
  --holdout-manifest data\forensics\holdout_split.json `
  --forensics-profile-out outputs\forensics\forensics_profiles_quality_filtered.json
```

可选：同时重建纹理（更慢，抽帧默认 24）：

```powershell
.\.venv\Scripts\python.exe scripts\run_hard_detection_pipeline.py build-profile `
  --include-texture `
  --max-frames 24 `
  --min-landmark-ratio 0.45 `
  --min-pose-ratio 0.35 `
  --forensics-profile-out outputs\forensics\forensics_profiles_quality_filtered.json
```

### 2）非 holdout 重校准（训练侧）

```powershell
.\.venv\Scripts\python.exe scripts\run_hard_detection_pipeline.py recalibrate `
  --forensics-profile outputs\forensics\forensics_profiles_quality_filtered.json `
  --limit 80 `
  --calibrator-out outputs\forensics\fused_hard_calibrator.json `
  --update-forensics-profile
```

### 3）holdout 全量硬判评估（出数字）

AU-only（快）：

```powershell
.\.venv\Scripts\python.exe scripts\run_hard_detection_pipeline.py evaluate `
  --forensics-profile outputs\forensics\forensics_profiles_quality_filtered.json `
  --calibrator outputs\forensics\fused_hard_calibrator.json `
  --max-frames 24 `
  --output outputs\forensics\fused_hard_detection_metrics.json
```

带纹理分支（慢，对应你问的 24 帧）：

```powershell
.\.venv\Scripts\python.exe scripts\run_hard_detection_pipeline.py evaluate `
  --include-texture `
  --max-frames 24 `
  --forensics-profile outputs\forensics\forensics_profiles_quality_filtered.json `
  --calibrator outputs\forensics\fused_hard_calibrator.json `
  --output outputs\forensics\fused_hard_detection_metrics_texture24.json
```

看结果：

```powershell
Get-Content outputs\forensics\fused_hard_detection_metrics.json | Select-String -Pattern "headline" -Context 0,12
```

`headline.generated_recall` = 生成召回率  
`headline.overall_accuracy` = 整体准确率（真+生成）  
`headline.coverage` 应为 `1.0`

## 关于 8 帧 / 24 帧

- 王兴 **source**（真假主信号之一）吃的是 **AU CSV 全序列**，不靠 8/24 抽帧
- `--max-frames 24` 主要影响 **纹理 / NR-VQA / 频域 / 身份** 分支
- 建议评估时纹理用 **24**；身份专项另用 `--identity-frames`（见 `evaluate_wangxing_source_detection_metrics.py`）

## 新增/改动文件

| 文件 | 作用 |
|------|------|
| `evaluator/modules/forensics/fused_hard_detector.py` | 王兴 source + forensics 融合硬判 |
| `evaluator/modules/forensics/authenticity_decision.py` | 判定 API（本流水线硬判模式） |
| `scripts/run_hard_detection_pipeline.py` | build / recalibrate / evaluate |
| `scripts/build_forensics_profiles.py` | 新增 `--min-landmark-ratio` / `--min-pose-ratio` |

## 注意

- holdout 样本不会进入画像训练（`--holdout-manifest`）
- 本流水线**不把不确定样本排除出分母**；要对比旧的拒识口径，仍可用 `evaluate_wangxing_source_detection_metrics.py`
- 训练跑完后，若要推对方工程：先把新 profile/calibrator 同步进 `evaluator/modules/assets/profiles/`，再 `--flat-host 对方工程`
