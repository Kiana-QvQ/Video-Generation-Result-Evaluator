## 1. 背景：为什么需要 V5.1（在 V5.0 之上）

### 1.1 V5.0 已证实

- 冻 V3 + 词典序 cascade **能保** 真伪指标。
- DriveHead JSON 逻辑回归 **能训出**，且不翻转 V3。
- 无完整四元组时 RankHead **正确禁用**，不会假装四档。
- 正式网页 **未** 默认暴露 V5。

### 1.2 仍存在的产品缺口

```text
缺口 A：用户要「一个质量分」表达越像实拍越高
缺口 B：旧表情证据（画像贴合主导）曾出现 AI 均值 > 实拍
缺口 C：无大规模 LTX 时，不能深训四分类 Rank，但仍要可校准连续分
缺口 D：四档标签是当前人工先验，不是永远不变的物理定律
```

### 1.3 表情证据误区（必须写进 V5.1 设计约束）

见 `docs/AI视频人工质量分档参考_20260819.md`：

| 证据 | 实拍均值 | AI 均值 |
|---|---:|---:|
| 表情证据 | 66.34 | **71.82** |
| 取证证据 | **71.42** | 66.47 |
| 身份证据 | 97.10 | 97.49 |

根因（方法/指标，非「V3 训坏」）：

```text
表情证据 ≈ 0.35 * compatibility_0_1（画像贴合）+ 若干面部运动项
AI 可以更「像王兴表情画像」同时仍是生成驱动
→ 禁止把 compatibility 当 s_realness 主特征
→ 取证方向（direction）已方向正确，应进入质量轴
```

### 1.4 常理与工程边界

**常理（采纳为产品目标）：**

```text
生成效果越好 → 应更接近实拍 → s_realness 应更高
```

**工程边界（必须写死）：**

```text
常理 ≠ 当前数据已自动满足四档序
训练集主是 真人 + Seedance + 伪假；LoRA/多图 ≈ 0
ppt 仅 2 组完整四元组 → 只够校准+验收，不够深训
```

## 2. V5.1 目标拆分（三层，禁止混成一个 logit）

| 层 | 目标 | 输出 | 谁负责 | 现数据 |
|---|---|---|---|---|
| **L1 决策** | AI vs 实拍 | `y_decision = y_v3` | 冻结 V3 | ✅ 已完成 |
| **L2 质量** | 多像实拍 | `s_realness ∈ [0,1]` | RealnessHead / calibrator | ⚠️ V5.1 新建 |
| **L3 展示** | 对外一个分 | `score_display` | cascade 单调映射 | ⚠️ 改用 s_realness |
| （可选）L4 档位提示 | 当前人工先验标签 | `band_hint` | policy，非决策 | 仅 development |

```text
禁止：用 L2/L3 改写 L1
禁止：用画像 compatibility 主导 L2
禁止：把固定四档枚举写死为唯一未来接口
允许：用当前四档先验校准 L2（development_only）
```

学术对应：

| 层 | 方向 |
|---|---|
| L1 | Detection（FTCN 族，已由 V3 承担） |
| L2 | One-class / 自然一致性 / 多信号实拍像真度（NACO、UNTAG、forensics direction） |
| L3 | 工程词典序（非论文 fusion magically） |
| L4 | Learning-to-rank / Attribution（RankSVM、RankNet、FAME；数据够才启用） |

## 3. 总体架构

### 3.1 三层 + 可选档位提示

```text
┌──────────────────────────────────────────────────────────────┐
│ L1 决策（冻结，继承 V5.0）                                      │
│   V3 → y_v3 ∈ {real, generated}，p_v3_real ∈ [0,1]           │
│   y_decision := y_v3                                         │
├──────────────────────────────────────────────────────────────┤
│ L2 质量轴 Realness（V5.1 核心）                                 │
│   特征：p_drive_eff, s_direction, p_v3_real, …               │
│   禁止：compatibility_0_1 作主特征；身份分抬真实度              │
│   输出：z_raw →（校准器）→ s_realness ∈ [0,1]                 │
├──────────────────────────────────────────────────────────────┤
│ L3 展示映射（词典序）                                           │
│   y_v3=real → score ∈ [0.75, 1.00] = 0.75 + 0.25*s_realness │
│   y_v3=AI   → score ∈ [0.00, 0.74] = 0.74 * s_realness      │
├──────────────────────────────────────────────────────────────┤
│ L4 band_hint（可选，development）                              │
│   仅展示解释；不改变 y_decision                                 │
│   有足够数据且 ordering_satisfied 前不得对外承诺                │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 与 V5.0 cascade 的关系

| 项目 | V5.0 | V5.1 |
|---|---|---|
| 决策 | `y_v3` | 同左 |
| AI 带映射 | `0.74 * p_drive_eff` | `0.74 * s_realness` |
| 真人带映射 | `0.75 + 0.25*(0.85 p_v3 + 0.15 p_drive_eff)` | `0.75 + 0.25 * s_realness` |
| RankHead | 数据门禁，默认关 | 仍关；档位改由 L4 hint 可选 |
| 无 calibrator | — | 回退 V5.0 公式（兼容） |

### 3.3 词典序不变量（单测必须）

```text
I1: y_decision == y_v3
I2: min(score_display | y_v3=real) > max(score_display | y_v3=AI)
I3: 同带内 s_realness ↑ ⇒ score_display ↑
I4: s_realness 特征集不含 compatibility_0_1（或权重强制为 0）
I5: 校准器未加载时行为 ≡ V5.0 cascade（regression）
```

## 5. L2：RealnessHead / Calibrator 规格

### 5.1 定义

```text
s_realness = P_proxy(视频像「王兴实拍采集」 | 特征)
不是：P(像王兴常做表情画像)
不是：P(身份是王兴)   ← 身份仅门控，不抬分
```

连续分语义：**越高越像实拍**。AI 内部相对高低反映相对「像真度」，不自动等于管线标签。

### 5.2 输入特征（Phase1 最小集）

**必须进入 `z_raw`（推荐权重初值）：**

| 符号 | 来源 | 初值权重 | 说明 |
|---|---|---:|---|
| `p_drive_eff` | DriveHead + coverage gate | 0.40 | 真驱动 vs 生成驱动 |
| `s_direction` | `authenticity_score._direction_score` 合成 | 0.35 | 取证方向；历史实拍>AI |
| `p_v3_real` | 冻结 V3 | 0.25 | 只作特征，不作决策比特 |

**权重上限（防 p_v3 独占质量轴）：**

```text
w3 (p_v3_real) ≤ 0.30
w1 + w2 ≥ 0.70（drive + direction 合计）
若消融发现 corr(s_realness, p_v3_real) > 0.95 且 AI 带内无区分力：
  → 降 w3 或 AI 带内改用仅 (p_drive_eff, s_direction) 重标定
```

**可选增强（Phase1.5，默认关闭，ablation 再开）：**

```text
temporal_naturalness_0_1
texture_stability_0_1
frequency_naturalness_0_1
ai_domain_inverse_0_1
```

**禁止（权重必须为 0 或根本不读）：**

```text
expression_profile.compatibility_0_1
identity.probability_0_1 用于抬 s_realness
FER 七类置信度
画像 top_profiles 距离
authenticity_score 的 expression 合成分（含 compatibility）
```

### 5.2.1 `s_direction` 与 Seedance 域偏置（必须知晓）

```text
现有 _direction_score 使用 seedance_domain_fit / ai_domain_inverse。
含义：对「像不像训练过的 Seedance 域」敏感，不一定公平对待 LoRA / 多图。
V5.1 Phase1：仍复用（方向整体正确，实现成本低）。
风险：LoRA 可能因「不像 Seedance」被误抬或误压。
缓解：
  1) 消融 A4/A2 对比；记录 test1/test2 各类均值
  2) Phase1.5 增加管线无关项（temporal/texture/frequency）权重
  3) 不得把 seedance_domain_fit 单独当 LoRA 排序依据
```

### 5.3 原始分与校准

#### 5.3.1 原始线性分

```text
z_raw = w1 * p_drive_eff
      + w2 * s_direction
      + w3 * p_v3_real
      + b

默认（未校准前）：
  w1=0.40, w2=0.35, w3=0.25, b=0
  各输入已在 [0,1]；缺失时用 0.5 并记 missing_mask
```

#### 5.3.2 校准器（二选一，推荐 B）

**方案 A：线性 pairwise / RankSVM（小样本）**

```text
在 ppt test1 的四元组上构造序对：
  real≻lora, real≻seedance, real≻multiref,
  lora≻seedance, lora≻multiref, seedance≻multiref
拟合 w（L2 强正则，C 小）；禁止隐藏层 MLP
```

**方案 B：固定 z_raw + Isotonic regression（推荐）**

```text
1. 用默认或 A 得到的 w 算 z_raw
2. 在 test1 四点上对目标序做 isotonic / 分段单调映射 → s_realness
3. 推理：s_realness = calibrator(z_raw)
4. 校准器写入 JSON，可版本化回滚
```

```text
目标序（当前人工先验，可配置）：
  ORDER = ("real", "lora", "seedance", "multiref")
  RANK  = {real:3, lora:2, seedance:1, multiref:0}
```

### 5.4 `s_direction` 抽取契约

复用 `evaluator/modules/wangxing/authenticity_score.py` 的 direction 合成逻辑：

```text
components:
  real_domain_fit_0_1
  ai_domain_inverse_0_1
  temporal_naturalness_0_1
  texture_stability_0_1
  frequency_naturalness_0_1
s_direction = 加权均值（与 _direction_score 一致）
```

不得改写该函数的生产语义以「讨好」ppt；若改权重，必须新 schema 版本并做消融。

### 5.5 缺失与门控

```text
若 p_drive_eff 缺失：用 0.5，drive_status 记入 trace
若 s_direction 缺失：用 0.5，direction_status=unavailable
若 calibrator 文件缺失：s_realness := clip(z_raw)；或整链回退 V5.0
coverage_q 仍只影响 p_drive_eff，不 gate 掉 V3
```

### 5.6 校准超参与防过拟合

```text
样本：仅 ppt test1（默认 1 组 × 4 条）
禁止：用 25+25 / 32+32 拟合 w 或 isotonic
禁止：隐藏层宽度 > 0 的深度排序网
正则：线性模型 C≤0.5 或等价 L2；isotonic 不作外推爆炸（夹到 [0,1]）
seed：写入 calibrator JSON
输出：wangxing_v5_realness_calibrator.json
```

## 6. L3：展示分与决策面

### 6.1 决策比特（不变）

```text
y_decision = y_v3
threshold_decision = V3 checkpoint 阈值（冻结）
旁路不得翻转 real↔AI
```

### 6.2 展示映射

```text
function cascade_score_v51(y_v3, s_realness):
    s = clamp(s_realness, 0, 1)
    if y_v3 == real:
        return 0.75 + 0.25 * s          # [0.75, 1.00]
    else:
        return 0.74 * s                 # [0.00, 0.74]
```

`score_band`（展示用）：

```text
y_v3=real → "real"
y_v3=AI 且无可靠 L4 → "ai_unspecified"
y_v3=AI 且 L4 启用且 ordering_satisfied → "lora"|"seedance"|"multiref"
```

### 6.3 与「越像实拍分越高」的关系

```text
同决策带内：s_realness 单调决定 score_display
跨决策带：词典序保证「判真人」永远高于「判 AI」的展示分
因此：质量轴负责「像真度」；决策带负责「真伪安全区」
```

### 6.4 回退路径

```text
V5_REALNESS_ENABLED=false 或 calibrator 缺失：
  使用 V5.0 cascade（p_drive_eff 映射）
  schema 仍可输出 s_realness=null, realness_status=disabled
```

```text
□ 缓存目录：建议 outputs/forensics/cache_wangxing_v5_1_ppt/
```

**缺 AU / 人脸失败时：**

```text

若 test2 可用条数 < 4：holdout 报告「incomplete」，不得宣称 ordering 通过
```



### 7.4 Holdout 验收（test2）

```text
指标：
  pairwise_ordering_rate：按 RANK 应大于的 6 对中满足比例
  class_mean 是否严格按 ORDER 递减（四点）
  词典序：若 test2 含 real，其 score_display 必须 > 同组三条 AI
门槛（默认）：
  pairwise ≥ 5/6 或 6/6（配置化）
  development_only=true 直至扩容数据
```

### 7.4.1 二分类集上的质量轴辅助指标（非决策）

```text
在 25+25 / 32+32 上额外报告（不参与拟合）：
  mean(s_realness | label=real)  ?≥?  mean(s_realness | label=AI)
  AUC(s_realness vs label)（仅诊断）
  与旧 expression 合成分的相关（期望不要接近 1.0）
通过参考：实拍均值 > AI 均值（软门槛，记录即可；硬门槛仍是 flip=0 + 词典序）
```

### 7.4.2 ppt 上 V3 判错时的处理

```text

不要求 y_v3 与管线标签一致。

  ppt 上 y_v3 与人工管线标签的混淆（例如 LoRA 被判 real）
若 y_v3(real_video)=AI：词典序仍按 y_v3 分段；该条 score 落入 AI 带
  → 记为「决策与先验冲突」；不因此改 V3
  → 不得为讨好先验而改阈值
```

### 7.5 关于「一组拿来训练」的精确定义

```text
允许：test1 上拟合线性 w / isotonic（弱校准）
禁止：test1 上训练深层网络、改 V3、改 Drive 主阈值、改 25+25 阈值
```
