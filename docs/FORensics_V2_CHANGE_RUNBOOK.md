# Default Forensics V2 With Change Negatives

This runbook keeps the current `facial_motion + texture + calibrator`
architecture and trains a parallel `forensics v2` profile that adds
`Change` negatives into the generated domain.

It does **not** overwrite the current default web profile unless you
explicitly promote it after review.

## Status Of The Five Items

1. Web presentation for `decision == uncertain`
Done. The web no longer needs to present `uncertain` as a soft "real"
verdict.

2. Web runtime config vs calibration config
Partially done. The web runtime now uses `max_frames=32`. The new
training command below will produce a matching 32-frame calibrator.

3. Default `forensics v2`
Implemented in code. You need to run the commands below.

4. Fusion weights redesign
Not applied yet. The new training report includes branch diagnostics so
we can decide whether texture needs to be down-weighted on the next pass.

5. Threshold-only fix
Not used. The v2 flow below retrains the profile and calibrator instead
of only moving a threshold.

## What The New Script Does

`prepare`

- fixes the `Change` split:
  - train negatives: `BaiJunZhiJiang`, `Happy`, `LeJiShengBei`
  - eval negatives: `YanWu`, `ImissU`
- writes a generated-train manifest for the 3 train clips
- writes a combined holdout manifest:
  - official real holdout
  - official Seedance holdout
  - `Change` eval negatives

`train`

- keeps the real domain as `MD_CL`
- keeps the generated base domain as `WangXing_Seedance`
- adds the 3 `Change` train clips into the generated training domain
- excludes the combined holdout from profile fitting
- builds a new motion profile and texture profile
- fits a **32-frame** calibrator
- writes a single web-consumable profile JSON with embedded calibrator
- writes a report JSON with:
  - overall validation metrics
  - per-group validation metrics
  - branch AUC diagnostics
  - `Change` batch diagnostics for all 5 clips

## Commands To Run

Run from the repo root with `.venv`.

### 1. Prepare protocol and manifests

```powershell
.\.venv\Scripts\python.exe scripts\build_forensics_v2_change.py prepare
```

### 2. Train and calibrate default `forensics v2`

```powershell
.\.venv\Scripts\python.exe scripts\build_forensics_v2_change.py train `
  --output-profile outputs\forensics\forensics_profiles_v2_change.json `
  --output-report outputs\forensics\forensics_v2_change_report.json
```

Optional stricter motion filtering:

```powershell
.\.venv\Scripts\python.exe scripts\build_forensics_v2_change.py train `
  --min-landmark-ratio 0.45 `
  --min-pose-ratio 0.35 `
  --output-profile outputs\forensics\forensics_profiles_v2_change_qf.json `
  --output-report outputs\forensics\forensics_v2_change_qf_report.json
```

## What To Check After Training

Open `outputs/forensics/forensics_v2_change_report.json`.

Focus on:

- `validation`
  - `roc_auc_real_vs_generated_raw`
  - `generated_decisions`
  - `branch_auc`

- `validation_by_group`
  - `official_real_holdout`
  - `official_seedance_holdout`
  - `change_eval`

- `change_batch_diagnostics`
  - verify `YanWu_Change.mp4` and `ImissU_Change.mp4`
  - confirm they do not drift back to `real_capture`

## Promotion Rule

Only promote the new profile if:

- `change_eval` improves materially versus the current default profile
- `official_real_holdout` does not collapse
- `YanWu_Change` no longer lands in `real_capture`

If the result is good, promote manually by backing up the current default
profile and copying the new one into place:

```powershell
Copy-Item outputs\forensics\forensics_profiles.json `
  outputs\forensics\forensics_profiles.backup_before_v2_change.json

Copy-Item outputs\forensics\forensics_profiles_v2_change.json `
  outputs\forensics\forensics_profiles.json -Force
```

## If Accuracy Is Still Not Good Enough

Then the next pass is **not** "move the threshold".

The next pass should use the new report to redesign fusion weights:

- if `texture_raw` AUC on `change_eval` is weak, reduce texture influence
- if `facial_raw` and `texture_raw` disagree strongly, send the clip to
  `uncertain`
- only after that do another calibrator fit
