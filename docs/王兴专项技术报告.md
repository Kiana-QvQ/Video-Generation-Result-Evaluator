# 定向专项 / 王兴评分方案

## 一、当前采用的算法

王兴专项只判断三件事：

### 1. 身份算法

- 使用 InsightFace / ArcFace 提取多帧人脸 embedding。
- 与王兴真人身份 profile、王兴 AI profile 和非王兴负样本比较。
- 根据人脸质量、有效帧比例和帧间一致性加权。
- 输出身份概率、帧一致性、有效脸帧和质量权重。
- 身份通过后，才进入表情画像判断。

### 2. 表情画像算法

- 输入 LibreFace AU CSV。
- 使用 AU intensity、AU presence、Face Mesh、pose、AU 速度和加速度。
- 与王兴真人的六类表情画像比较：
  `smile / anger / surprise / fear / sadness / disgust`。
- 通过稳健距离计算画像兼容度。
- 输出最接近表情、第二接近表情、画像贴合度、AU 关系和动态性。

### 3. 真假取证算法

- 面部运动：AU 动态、landmark、pose、AU 关系和时序自然度。
- 纹理取证：face-crop、全帧纹理、光流残差和纹理 flicker。
- 频域取证：DCT、FFT 和频域异常。
- 质量辅助：MUSIQ/NR-VQA、有效帧和检测质量。
- 真人/AI profile 进行域拟合，再经过概率校准器输出真实拍摄概率。

## 二、网页雷达展示

真假方向性雷达包含：

```text
真实域贴合、AI 域贴合、时序异常、纹理残差、频域异常
```

其中真实域贴合越高越接近实拍；其他异常或 AI 域指标越高，越偏向 AI。
雷达分数是证据展示，不等于真实拍摄概率。

网页最终按真实拍摄概率二分类：

```text
>= 50%：偏向真实拍摄
<  50%：偏向 AI 生成
```

## 三、后续优化示例

- 建立黑背景、强侧光、同机位、同脚本的王兴实拍对照集。
- 增加表情转换窗口：平静、微笑、大笑、哭泣的开始、峰值和结束。
- 增加眼睛、嘴部、眼下区域的 face-crop 局部时序。
- 使用 AU/landmark 速度、加速度和连续异常比例。
- 将身份/source 作为身份质量门，不再直接提高真实概率。
- 使用真实域、AI 域和困难样本重新训练网页融合器。

## 四、当前尝试的 PT v4

PT v4 在原有视频/AU 时序模型上增加：

- 独立 face geometry 分支；
- landmark、pose 和人脸质量特征；
- 表情转换与局部区域时序特征；
- 眼睛、嘴部、泪水、眉毛和下巴区域统计；
- 亮度、颜色、gamma、压缩训练增强；
- 视频、AU、人脸几何和时序特征联合输出。

PT v4 仍需完成 GPU 训练、官方 holdout 验证和独立 25+25、32+32 测试。
