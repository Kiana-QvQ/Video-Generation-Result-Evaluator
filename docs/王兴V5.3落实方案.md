## 1. 背景：为什么需要 V5.3（在 V5.2 之上）

### 1.1 结构性矛盾（不是 patch bug）

V5.2 离线四档序依赖两个条件同时成立：

```text
1. RankHead 拉开 AI 三档（特征驱动，与文件名无关）✅ 可复用到现网
2. holdout 真人展示分进实拍带，依赖排序组已知 label=real + role_anchor ❌ 公网不可用
```

公网单条上传没有 ground-truth 标签。若用「文件名含真人」触发 `role_anchor`，会把**演示口径**伪装成**检测能力**，对用户不透明且易误判。

因此 V5.3 的目标不是再改 RankHead，而是定义 **Runtime Display Layer（L3.5）**：

```text
在不动 L1 决策、不破坏 L3 词典序的前提下，
为「领导同批对比」和「单条盲测」分别给出可验收的展示策略。
```

### 1.2 产品缺口（V5.3 必须关掉）

```text
缺口 A：离线 0.92 与现网单条分数不一致 → 领导质疑「有没有接入 V5.2」
缺口 B：去掉文件名后，holdout 真人无法自动进实拍带 → 四档序在单条路径断裂
缺口 C：真实拍摄概率 vs 真实性取证 语义混淆 → 需写死双字段含义
缺口 D：ppt 四视频同测是真实使用场景，但 job 级组内协议未规格化
缺口 E：V3 holdout 真人 recall 不足（prior_conflict=1）→ 中长期须数据/模型迭代
```

### 1.3 论文与演进结论（必须遵守）

见 `docs/论文与技术研究记录.md` §三、`docs/王兴V5.2落实方案.md` §1.3：

| 结论 | V5.3 工程含义 |
|---|---|
| 二分类学不出四档 | 四档序只能来自 Rank + 组上下文，不能来自 V3  alone |
| RankNet / RankSVM | 组内相对序、pairwise 验收语言沿用 V5.2 |
| FAME / CapST | 生成器归因是 **V5.4+** 增强方向，不是 V5.3 主路径 |
| LipForensics / AUNet | 提升 V3 recall / 时序特征，属 **V5.4-enhance**，不替代 V5.3 展示层 |
| 排序不得改 V3 决策 | L3.5 只改 `score_display`，不改 `y_decision` |
| compatibility ≠ 真实性 | 禁止用画像符合度触发实拍带 |

### 1.4 常理与工程边界

**常理（采纳）：**

```text
同批、同设定对比时：越像实拍 → 展示分越高
AI 内部：LoRA > Seedance > 多图（当前人工先验 ORDER）
用户未声明视频类型时：系统不得假装知道 ground truth
```

**工程边界（写死）：**

```text
V5.3 不训练新深度网（除非走路线 A 的 V3 微调，单独立项）
V5.3 默认不读取 upload 原始文件名作 ranking 标签
V5.3 组内协议只对 complete_query 生效；单条路径不伪造四档保证
manifest 显式角色仅用于内网回归 / 演示，不默认对公网用户开启
```

## 2. V5.3 目标拆分（五层，在 V5.2 四层之上加 L3.5）

| 层 | 目标 | 输出 | 谁负责 | V5.3 变化 |
|---|---|---|---|---|
| **L1 决策** | AI vs 实拍 | `y_decision = y_v3` | 冻结 V3 | 不变 |
| **L2 质量** | 多像实拍 | `s_realness` | V5.1 calibrator | 不变 |
| **L3 展示带** | 词典序一个分 | `score_display` base | cascade V5.2 | 不变 |
| **L4 细档** | AI 相对序 | `s_rank` / `band_hint` | RankHead V5.2 | 不变 |
| **L3.5 现网展示** | 无标签恢复四档 / 口径一致 | `score_display_final` | **V5.3 新增** | 本文 |

```text
L3.5 只允许：
  - 在 AI 带内重排（继承 L4）
  - 在通过 gate 时将 score_display 映射进实拍带（仅展示）
  - 在 complete_query job 内做组级 display rescoring

L3.5 禁止：
  - 修改 y_decision
  - 用文件名推断 label=real
  - 无 gate 地将所有高 s_realness 的 AI 视频抬进实拍带
```

学术对应：

| 层 | 方向 | 参考 |
|---|---|---|
| L1 | Deepfake detection | V3 / FTCN 族 |
| L2 | One-class / naturalness | NACO 思想；forensics + Drive |
| L3 | Engineering lexicographic display | 项目内 cascade |
| L4 | Learning-to-rank | RankNet / RankSVM（Burges; Joachims） |
| L3.5 | Contextual re-ranking / calibrated display | Listwise reranking 思想；**非**论文 magic fusion |

## 3. 总体架构

### 3.1 V5.3 数据流（现网单条）

```text
upload video + AU
    │
    ▼
build_feature_row(label=WEB_NEUTRAL_LABEL)   # 固定 seedance，不读文件名
    │
    ▼
cascade_score_v52(prior_conflict=false)      # 网页无 GT，不标记 prior_conflict
    │
    ▼
score_display_base                             # V5.2 输出
    │
    ▼
apply_runtime_display_policy(mode=single)      # V5.3 L3.5（默认 passthrough）
    │
    ▼
patch forensics:
  calibrated_real_probability_0_1 ← score_display_final
  binary_decision ← V3 only
```

### 3.2 V5.3 数据流（同 job complete_query）

```text
job videos [v1..v4] 全部评完
    │
    ▼
每条 score_display_base + s_realness + s_rank + y_v3
    │
    ▼
detect complete_query（四类特征/manifest，非文件名）
    │
    ▼
group_display_rescore(rows)                    # Phase C
    │ optional
    ▼
content_realness_gate(row)                     # Phase B（单条也可启用）
    │
    ▼
score_display_final × N
```

### 3.3 与 V5.2 离线评测的关系

| 场景 | V5.2 离线 | V5.3 目标 |
|---|---|---|
| PT evaluate + 已知 manifest label | `role_anchor` on label=real | **保留**（离线不变） |
| Web 单条盲测 | 曾用文件名 mimic label | **禁止**；走 L3.5 Phase B 或 passthrough |
| Web 同 job 四视频 | 未规格化 | Phase C 组内重排 |
| leadership_brief | 含 role_anchor 均值 | 新增 `web_single` / `web_group` 分项报告 |

## 4. 路线规格（A–E）

V5.3 不要求五路线全部实现；推荐组合见 §8。

### 4.1 路线 A — V3 / 数据层根治（中长期）

**目标：** 减少 `prior_conflict`，让 L1 与 L2 自然一致。

| 动作 | 数据 | 验收 |
|---|---|---|
| 扩充 holdout 类真人进 V3 训练 | 新真人 clip，排除 25+25/32+32 | holdout prior_conflict=0 或 ↓ |
| 难负例 / 域增强 | AltFreezing 思想（研究） | 25+25 Real recall ≥ 96% 不掉 |
| Drive + 时序增强 | LipForensics 预训练嘴部支路（→ V5.4） | AI 带内序不降 |

**论文参考：**

- LipForensics（嘴部时空不一致）：https://arxiv.org/pdf/2012.07657
- AltFreezing / 时序一致性族：见 `docs/王兴V5落实方案.md` §4
- 本地状态：见 `docs/论文与技术研究记录.md` — **未**论文级复现 backbone

**注意：** 路线 A 不改变 V5.3 展示契约；可与 B/C 并行。

### 4.2 路线 B — 内容驱动实拍带 gate（`s_realness_gate`）

**目标：** 在不读文件名的前提下，对「V3=AI 但 s_realness 显著高于 AI 簇」的样本，将 **展示分** 映射进实拍带（同 `role_anchor` 公式，触发条件改为内容阈值）。

**触发条件（拟议，须在 train 标定、holdout 验收）：**

```text
y_v3 == generated
AND s_realness >= T_high          # 在 ranking train 组 AI 分布 P95 之上
AND s_rank <= T_rank_cap          # 避免 LoRA 被误抬（可选）
AND gate_enabled == true
→ score_display = 0.75 + 0.25 * s_realness
→ rank_reason = "content_realness_gated_display"
→ prior_conflict_display = true（仅诊断；y_decision 仍 generated）
```

**阈值标定数据：**

```text
data/ranking/wangxing_v5_2/manifest.json  # train 组 AI 类 s_realness 分布
禁止：用 holdout ppt_test2 拟合 T_high（只能验收）
```

**验收指标（§6.3）：**

```text
holdout 真人（V3=AI）：score_display ≥ 0.75
holdout AI 三档：零样本被误抬进实拍带（false_positive_count=0）
25+25 / 32+32：decision_flip=0；词典序不被破坏
```

**论文思想（非直接复现）：**

- One-class / 自然度代理：NACO、realness calibrator 思路（V5.1 已实现轻量版）
- 阈值 gate 是 **工程校准**，不是论文 end-to-end 保证

### 4.3 路线 C — Job 组内 display rescoring（`group_display_rescore`）

**目标：** ppt 式「一次上传 4 条同 prompt 对比」时，在不读文件名的前提下恢复四档 ORDER。

**complete_query 检出（禁止文件名）：**

```text
条件 1：同一 job_id 内恰好 4 条视频评测完成
条件 2：manifest 声明 completeness=full（内网/regression）
   或 启发式：4 条的 s_rank 覆盖 AI 三档 + 1 条 s_realness 为组内最大且 gap ≥ G_min
条件 3：非 25+25 / 32+32 路径
```

**组内算法（拟议 Phase C1 — 相对序 + 实拍带分配）：**

```text
1. 对组内每条保留 y_v3 不变
2. 按 s_realness 降序；若 top 与 second 的 Δs_realness ≥ G_min：
     top → 映射实拍带 score_display = 0.75 + 0.25 * s_realness_top
3. 其余 y_v3=AI 条目：按 s_rank 降序映射 DEFAULT_BANDS（lora/seedance/multiref）
4. 强制组内 ORDER 单调：display(top) > display(2nd) > display(3rd) > display(4th)
5. rank_reason = "group_display_rescore_v1"
```

**complete_query 验收：**

```text
ppt_test1 + ppt_test2 各 4 条 → display_order_satisfied=true
same_prompt 8 条 class_mean 与 V5.2 §0.7 偏差 ≤ 0.05
组内任一条 y_v3 不被修改
```

**论文参考：**

- RankNet pairwise / listwise reranking（Burges et al.）
- 组内 rescoring 是 **工程 listwise 后处理**，不是重新训练 RankHead

### 4.4 路线 D — 显式 manifest 元数据（内网 / 回归）

**目标：** 离线 PT/Web 对齐、内网演示、自动化回归 —— **不**作为公网默认路径。

**manifest 扩展（在 V5.2 schema 上增量）：**

```json
  "compatible_with": "wangxing_v5_2_ranking_manifest_v1",
  "runtime_mode": "offline_eval|web_regression|public_single",
  "groups": [
    {
      "group_id": "ppt_test2",
      "split": "holdout",
      "completeness": "full",
      "runtime_role_source": "manifest_explicit",
      "videos": {

        "lora": "...",
```


### 4.5 路线 E — 产品口径拆分（立即可用，零模型改动）

## 7. 算法与论文落地映射（V5.3 增量）

### 7.1 直接相关的论文 / 技术

| 论文/技术 | 与 V5.3 的关系 | 落地程度 |

| **RankNet**（Burges et al., ICML 2005） | 组内相对序、pairwise 验收语言 | V5.2 已落地；V5.3 组内后处理沿用 |
| **RankSVM**（Joachims） | 小样本序备选 / 消融 | V5.2 已支持；V5.3 不新增 |

| **NACO / one-class 思想** | 路线 B：`s_realness` 作自然度 proxy | V5.1 calibrator 已轻量实现 |
| **Listwise / contextual reranking** | 路线 C 组内 rescoring | **工程后处理**，非新训练 |

| 组内 rescoring 修改 y_v3 | 违反 V5.0 禁令 |
| 用 holdout 拟合 gate 阈值 | 泄漏验收 |
