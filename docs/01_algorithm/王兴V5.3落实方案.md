## 1. 背景：为什么需要 V5.3（在 V5.2 之上）

### 1.1 结构性矛盾（不是 patch bug）

V5.2 离线四档序依赖两个条件同时成立：

```text
1. RankHead 拉开 AI 三档（特征驱动，与文件名无关）✅ 可复用到现网
2. holdout 真人展示分进实拍带，依赖排序组已知 label=real + role_anchor ❌ 公网不可用
```

公网单条上传没有 ground-truth 标签。若用「文件名含真人」触发 `role_anchor`，会把**演示口径**伪装成**检测能力**，对用户不透明且易误判。

因此 V5.3 分三条主路径并行，而不是单一「展示 patch」：

```text
公网长期    → 路线 E + B（口径 + 内容 gate，无文件名）
内网回归    → 路线 D（manifest 显式角色，淘汰 role_anchor）
中期阶段 3  → 路线 A（V3 数据/重训，从根上压 prior_conflict）
```

### 1.2 产品缺口（V5.3 必须关掉）

```text
缺口 A：离线 0.92 与现网单条分数不一致 → 领导质疑「有没有接入 V5.2」
缺口 B：去掉文件名后，holdout 真人无法自动进实拍带 → 四档序在单条路径断裂
缺口 C：真实拍摄概率 vs 真实性取证 语义混淆 → 需写死双字段含义
缺口 D：ppt 四视频同测是真实使用场景，但 job 级组内协议未规格化
缺口 E：V3 holdout 真人 recall 不足（prior_conflict=1）→ 中长期须数据/模型迭代
```

### 1.3 论文与演进结论（必须遵守）

见 `docs/01_algorithm/论文与技术研究记录.md` §三、`docs/01_algorithm/王兴V5.2落实方案.md` §1.3：

| 结论 | V5.3 工程含义 |
|---|---|
| 二分类学不出四档 | AI 三档靠 RankHead；真人靠 V3（路线 A）或展示 gate（路线 B） |
| RankNet / RankSVM | 沿用 V5.2；内网验收语言不变 |
| holdout 真人 V3 误判 | **中期路线 A** 补训；非 role_anchor / 非文件名 |
| FAME / CapST | V5.4+ 可选；不进 V5.3 主路径 |
| LipForensics / AUNet | 可作为路线 A 增强项（V5.4），非 V5.3 必需 |
| 排序不得改 V3 决策 | 全路线只动 score_display，不动 y_decision |

### 1.4 常理与工程边界

**常理（采纳）：**

```text
同批、同设定对比时：越像实拍 → 展示分越高
AI 内部：LoRA > Seedance > 多图（当前人工先验 ORDER）
用户未声明视频类型时：系统不得假装知道 ground truth
```

**工程边界（写死）：**

```text
公网：路线 E + B；禁止 filename / role_anchor
内网：路线 D；manifest 为 role_anchor 唯一合法替代
中期：路线 A 为 prior_conflict 主解；验收前不得对外宣称「V3 已判对 holdout 真人」
路线 C（组内启发式重排）不纳入主路径
manifest 显式角色仅用于内网 regression / leadership 对照
```

### 4.1 路线 A — V3 / 数据层根治（**中期 · 阶段 3，prior_conflict 主解**）

**目标：** 从根上减少 `prior_conflict`，使 holdout 真人由 V3 判 `real`，展示分自然进实拍带，**不再依赖 role_anchor 或 B gate 掩盖 L1 失误**。

| 动作 | 数据 | 验收 |
|---|---|---|
| 扩充 holdout **同类**真人进 V3 训练/dev | ppt 同设定、同身份、相近机位/光照的新真人 clip | 不进 25+25 / 32+32 终测 |
| 难负例 / 域增强 | 与 holdout AI 三档共存的 hard negative | 25+25 Real recall ≥ 96% |
| 重训 / 微调 V3 | 冻结构或受控微调；权重版本化 | holdout prior_conflict=0 |
| 可选增强 | LipForensics 嘴部时序（可并行 V5.4） | AI 带内 Rank 序不降 |

**数据协议（路线 A 专用）：**

```text
data/v3_retrain/wangxing_v5_3/
  holdout_like_real_manifest.json    # 声明来源、与 ppt_test2 相似度、禁止进终测
  excluded_basenames.txt             # 25+25 / 32+32 / ppt holdout 源文件
  v3_retrain_split.json              # train / dev / holdout 划分

硬规则：
  - holdout ppt_test2 四条永不进 V3 fit 列表
  - 新增真人须记录 prompt_id / 机位 / 光照元数据
  - 重训后必须重跑 V5.2 rank + binary gate 全链路
```

**论文参考：**

- 域适应 / 难负例：AltFreezing 思想（见 `docs/01_algorithm/王兴V5落实方案.md` §4）
- 时序取证：LipForensics https://arxiv.org/pdf/2012.07657（可选 V5.4 并行）
- 本地状态：`docs/01_algorithm/论文与技术研究记录.md` — LipForensics **未**论文级复现

**与展示层关系：** 路线 A 成功后，公网可默认关 B gate 或放宽阈值；内网 D 仍保留作 regression 金标准。

### 4.2 路线 B — 内容驱动实拍带 gate（**公网长期 · 与 E 组合**）

**定位：** 公网单条盲测在路线 A 完成前的**展示层补洞**；路线 A 验收后降为兜底或默认关闭。

**目标：** 在不读文件名的前提下，对「V3=AI 但 s_realness 显著高于 AI 簇」的样本，将 **展示分** 映射进实拍带（公式同历史 role_anchor，**触发条件改为内容阈值**）。

**触发条件与完整公式见附录 B。** 摘要：

```text
y_v3 == generated
AND s_realness >= T_high
AND realness_status == ok
AND gate_enabled == true
→ score_display_final = clamp(0.75 + 0.25 * s_realness, 0.75, 1.0)
→ prior_conflict_display = true（仅诊断；y_decision / binary_decision 不变）
```

**阈值标定数据：**

```text
data/ranking/wangxing_v5_2/manifest.json  # train 组 AI 类 s_realness 分布
禁止：用 holdout ppt_test2 拟合 T_high（只能验收）
```

**验收指标（§6.3）：**

```text
holdout 真人（V3=AI）：score_display ≥ 0.75
holdout AI 三档：零样本被误抬进实拍带（false_positive_count=0）
25+25 / 32+32：decision_flip=0；词典序不被破坏
```

**论文思想（非直接复现）：**

- One-class / 自然度代理：NACO、realness calibrator 思路（V5.1 已实现轻量版）
- 阈值 gate 是 **工程校准**，不是论文 end-to-end 保证

### 4.3 路线 C — Job 组内 display rescoring（**备选 · 不纳入主路径**）

> **状态：降优先级。** 领导四档与 prior_conflict 优先由 **路线 A（V3）+ 路线 D（内网 manifest）+ 路线 B（公网 gate）** 解决。路线 C 仅保留规格供未来 ppt 批测启发式实验，**不作为 V5.3 发布门槛**。

**complete_query 检出（禁止文件名）：**

```text
条件 1：同一 job_id 内恰好 4 条视频评测完成
条件 2：manifest 声明 completeness=full（内网/regression）
   或 启发式：4 条的 s_rank 覆盖 AI 三档 + 1 条 s_realness 为组内最大且 gap ≥ G_min
条件 3：非 25+25 / 32+32 路径
```

**组内算法（拟议 Phase C1 — 相对序 + 实拍带分配）：**

```text
1. 对组内每条保留 y_v3 不变
2. 按 s_realness 降序；若 top 与 second 的 Δs_realness ≥ G_min：
     top → 映射实拍带 score_display = 0.75 + 0.25 * s_realness_top
3. 其余 y_v3=AI 条目：按 s_rank 降序映射 DEFAULT_BANDS（lora/seedance/multiref）
4. 强制组内 ORDER 单调：display(top) > display(2nd) > display(3rd) > display(4th)
5. rank_reason = "group_display_rescore_v1"
```

**complete_query 验收：**

```text
ppt_test1 + ppt_test2 各 4 条 → display_order_satisfied=true
same_prompt 8 条 class_mean 与 V5.2 §0.7 偏差 ≤ 0.05
组内任一条 y_v3 不被修改
```

**论文参考：**

- RankNet pairwise / listwise reranking（Burges et al.）
- 组内 rescoring 是 **工程 listwise 后处理**，不是重新训练 RankHead

## 17. 技术附录 B：Content Gate 完整规格（路线 B）

### B.1 阈值定义

在 **ranking train 组**、标签 ∈ `{lora, seedance, multiref}` 的样本上：

```text
P95(label) = percentile_95(s_realness | label)
T_high = max(P95_lora, P95_seedance, P95_multiref) + margin

margin ∈ {0.02, 0.03, 0.05}   # 仅在 train 上网格选优
T_rank_cap 可选               # 默认 null；若启用则 s_rank ≤ T_rank_cap 才允许 gate
```

**禁止：** 用 `ppt_test2` holdout 拟合 `T_high` / `margin`（只能验收 FP 率）。

产物：`outputs/forensics/wangxing_v5_3_display_gate.json`

### B.2 触发与映射（伪代码）

```text
function apply_content_gate(row, policy):
  assert row.y_decision unchanged forever

  if not policy.content_gate.enabled:
    return passthrough(row)

  if row.s_realness is None or row.realness_status not in {"ok"}:
    row.content_gate_applied = false
    row.score_display_final = row.score_display_base
    row.fallback_reason = "realness_unavailable"
    return row

  if not isfinite(row.s_realness) or not isfinite(row.score_display_base):
    row.content_gate_applied = false
    row.fallback_reason = "non_finite_score"
    # 禁止写入 UI calibrated 字段
    return row

  if row.y_v3 != "generated":
    row.score_display_final = row.score_display_base
    row.content_gate_applied = false
    return row

  if row.s_realness >= policy.T_high and (T_rank_cap is null or row.s_rank <= T_rank_cap):
    row.score_display_final = clamp(0.75 + 0.25 * row.s_realness, 0.75, 1.0)
    row.content_gate_applied = true
    row.prior_conflict_display = true    # 仅诊断：展示进实拍带但 V3 仍 AI
    row.rank_reason = "content_realness_gated_display"
  else:
    row.score_display_final = row.score_display_base
    row.content_gate_applied = false
    row.prior_conflict_display = false

  return row
```

### B.3 不变量（单测必须）

```text
I_gate_1: y_decision == y_v3（Gate 前后不变）
I_gate_2: binary_decision == map_v3(y_v3)（Gate 不得改真实性取证）
I_gate_3: content_gate_applied=true ⇒ score_display_final ≥ 0.75
I_gate_4: holdout AI 三档在 gate 开启时 false_positive_to_real_band = 0
```

### B.4 与 `prior_conflict` 字段区分

| 字段 | 含义 | 谁写 |
|---|---|---|
| `prior_conflict` | L1：已知 GT label 与 V3 决策冲突（离线/manifest 才有 GT） | 离线 evaluate |
| `prior_conflict_display` | L3.5：V3=AI 但展示分进实拍带（Gate/manifest 抬升） | runtime display |

公网单条无 GT → `prior_conflict` 恒 `false`；Gate 触发时只设 `prior_conflict_display=true`。
