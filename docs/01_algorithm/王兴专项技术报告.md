# 定向专项 / 王兴技术报告

## 一、专项目标

王兴专项只判断三个问题：

```text
1. 视频人物是否为王兴
2. 面部表情是否符合王兴表情画像
3. 视频更接近真实拍摄还是 AI 生成
```

身份像王兴，不等于视频是真拍；表情像王兴，也不等于没有 AI 痕迹。

## 二、当前采用的算法

### 1. 身份识别

使用 ArcFace/InsightFace 对视频多帧人脸提取特征，与王兴真人身份画像、王兴 AI 画像和非王兴负样本比较，并结合有效帧比例、帧间一致性和人脸质量加权。

### 2. 表情画像

使用 LibreFace AU、Face Mesh、pose、AU 速度和加速度，与王兴真人的微笑、愤怒、惊讶、紧张、悲伤、厌恶六类表情画像进行距离匹配。

输出最接近表情、画像贴合度、AU 关系、面部动态、关键点覆盖和表情事件。

### 3. 真假取证

使用面部运动、AU/landmark 时序、face-crop 纹理、全帧纹理、光流残差、纹理 flicker、DCT/FFT 频域和 MUSIQ/NR-VQA。

真人/AI profile 先计算原始域证据，再使用校准器生成真实拍摄概率。

当前网页取证雷达展示：

```text
真实域贴合、AI 域贴合、时序异常、纹理残差、频域异常
```

## 四、后续优化和 PT v4

后续网页优化方向：

- 增加黑背景、强侧光、同机位王兴真人纹理 profile；
- 增加平静、微笑、大笑、哭泣的表情转换窗口；
- 加入眼睛、嘴部和眼下区域局部时序；
- 用困难真人和困难 AI 重新校准真实性概率。

PT v4 正在尝试加入：

- 人脸几何分支；
- landmark/pose 质量特征；
- AU 和表情转换时序；
- 眼睛、嘴部、泪水区域特征；
- 亮度、颜色、gamma 和压缩增强。

PT v4 仍需完成 GPU 训练、官方 holdout、25+25 和 32+32 测试。
