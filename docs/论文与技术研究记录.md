### 1. Diffusion Renderer

**论文标题**

`Diffusion Renderer: Neural Inverse and Forward Rendering with Video Diffusion Models`

**文件**

`C:\Users\zhanghaotian\Desktop\工作\论文\2501.18590v2.pdf`

**核心方法**

- 将神经逆渲染和神经前向渲染放在同一个视频扩散框架中。
- 逆渲染阶段从图像或视频估计几何、材质和光照相关的 G-buffer。
- 前向渲染阶段根据 G-buffer 和环境光条件生成照片级图像，不依赖完整的显式路径追踪。
- 使用合成数据训练基础能力，再用逆渲染模型为真实视频自动生成伪标签，减轻真实配对数据缺失的问题。
- 论文使用 Stable Video Diffusion 作为基础模型，并通过专门的属性条件和环境光编码进行控制。

**论文原文结论**

- 论文报告其方法在逆渲染、前向渲染和重新打光任务上超过对比方法，尤其强调复杂阴影、反射和真实场景泛化。
- 单步模型在误差敏感的光度指标上具有速度和稳定性优势，但在高频细节和感知质量上可能更模糊。
- 多步随机模型更适合重新打光和前向渲染中的真实细节生成。

**论文原文局限**

- 基于 Stable Video Diffusion，推理仍偏离线，速度有待通过蒸馏优化。
- 编辑结果可能出现轻微颜色或纹理变化。
- 真实视频自动标注依赖现成光照估计器，标注误差会限制效果。

**本地对应与结论**

- 本机存在 `D:\Pycharm2023.21\project\光影\DiffusionRenderer`，包括 `configs`、`inference`、`train`、`models` 等目录。
- 当前证据足以记录为“部署/工程参考”，不足以记录为“完成论文复现”。
- 对当前工作的启发是：光照控制不只是修改亮度，还需要把几何、材质、环境光和时序一致性作为条件；这属于技术路线总结，不是本地复现实验结果。

### 2. InstaFace

**论文标题**

`InstaFace: Identity-Preserving Facial Editing with Single Image Inference`

**文件**

`C:\Users\zhanghaotian\Desktop\工作\论文\InstaFace：带有单一图像推断的身份保护面部编辑.pdf`

**核心方法**

- 只使用一张推理图像进行身份保持的面部编辑。
- 使用 3DMM 条件图和 3D Fusion Controller，同时控制姿态、表情和光照。
- 使用面部识别编码器保留身份细节，再使用 CLIP 图像编码器保留背景、发型、饰品等更广义语义。
- 先在 FFHQ 和 DECA 条件上学习面部重演属性，再针对单张身份图像进行微调。

**论文原文结论**

- 论文报告其方法在身份保持、照片真实感、姿态/表情/光照控制方面优于若干对比方法。
- 面部识别特征和 CLIP 语义特征结合后，身份和非面部上下文保持更稳定。
- 单图推理降低了多图身份数据的要求，适合身份保持的面部编辑场景。

**论文原文局限**

- 输入为偏角或极端姿态时，身份可能偏离目标。
- 极端亮度条件下可能出现颜色准确性问题。
- DECA 的估计误差可能引入轻微表情偏差。

**本地对应与结论**

- 本机有 `光影\IdentityRelightCommon`、`光影\FaceLight` 等面部光照和身份相关工程，但没有发现名称和流程都对应 InstaFace 的直接复现。
- 当前应归档为“身份保持面部编辑方向的论文参考”，不能写成“使用了 InstaFace 完成身份编辑”。
- 对当前评估器的启发是：身份一致性需要结合脸部局部特征和整体语义，不能只依赖单一人脸相似度。

### 3. RenderFormer

**论文标题**

`RenderFormer: Transformer-based Neural Rendering of Triangle Meshes with Global Illumination`

**文件**

`C:\Users\zhanghaotian\Desktop\工作\论文\renderformer-paper.pdf`

**核心方法**

- 将三角网格场景编码为序列 token，用 Transformer 直接预测带全局光照的图像。
- 第一阶段建模三角形之间与视角无关的光传输。
- 第二阶段将光线束 token 转换为像素块，并结合第一阶段的三角形序列生成图像。
- 通过三维空间位置编码表达三角形相对位置，不需要针对每个场景单独训练。

**论文原文结论**

- 论文显示 RenderFormer 可以在不进行场景级微调的情况下处理反射、阴影、间接光和多光源。
- 训练范围内的三角形数量、光源数量和视角变化可以较好地泛化。
- 多阶段 Transformer 的拆分能够兼顾全局光传输和视角相关成像。

**论文原文局限**

- 注意力计算为二次复杂度，训练和推理的三角形数量受到资源限制。
- 超过训练范围的光源数量、光源尺寸、反射次数、相机位置和分辨率会出现细节丢失。
- 场景内光源、彩色光源和空间变化材质仍需要扩展训练或组合策略。

**本地对应与结论**

- 本地 `D:\Pycharm2023.21\project\renderformer` 有 `infer.py`、`scene_processor`、`renderformer\models`、示例场景和预训练权重。
- `output` 目录中确认存在多组 PNG/EXR 渲染结果，包括 `cbox` 和 `blend_scene` 场景。
- 这篇论文可以记录为“本地开源项目部署/推理验证”，但本地输出不是论文表格的重新测量。
- 论文对当前工作的直接启发是：复杂光照可以被拆成场景条件、光传输和视角成像三个层次；同时要显式记录模型训练分布外的失效边界。

### 4. Facial Microscopic Structures Synthesis

**论文标题**

`Facial Microscopic Structures Synthesis from a Single Unconstrained Image`

**文件**

`C:\Users\zhanghaotian\Desktop\工作\论文\单张无约束图像的面部显微结构综合.pdf`

**核心方法**

- 提出 FLEX，从单张自然拍摄的人脸图像合成皱纹和毛孔等面部微结构。
- 使用参数化的皱纹/毛孔表示和图神经网络模拟相邻微结构的关系。
- 使用 Direction Distribution Similarity 约束皱纹方向分布，同时结合视觉相似度进行优化。
- 生成微结构位移图，并可与 FaceScape、DECA、HRN 等宏观面部重建方法组合。

**论文原文结论**

- 论文报告 FLEX 能从模糊、无约束的面部皮肤图像中恢复具有相似密度和方向特征的微结构。

- 论文强调微结构可以作为宏观面部几何之外的真实感补充。

**论文原文局限**

- 主要表示凹陷结构，无法覆盖鼻尖等区域的凸起结构。
- 微结构受光照和视角影响，跨光照条件不能保证一致。
- 论文明确提到高保真面部微结构合成存在被用于伪造的风险。

**本地对应与结论**

- 本机存在面部细节、纹理和取证相关代码，但未找到 FLEX 的直接实现、训练集或论文级复现实验。

### 5. PI-Light

**论文标题**

`PI-Light: Physics-Inspired Diffusion for Full-Image Relighting`

**文件**

`C:\Users\zhanghaotian\Desktop\工作\论文\2601.22135v1.pdf`

**核心方法**

- 用两阶段框架处理全图重新打光：先进行图像内在属性估计，再进行神经前向渲染。
- 使用 batch-aware attention 改善一组图像中内在属性预测的一致性。
- 在前向渲染中加入物理启发的光传输约束，让扩散模型更接近可解释的光照变化。
- 使用只表示前半球的光照条件，减少自发光物体和背景已有光照的干扰。
- 构建受控光照的数据集，支持逆渲染和前向渲染训练。

**论文原文结论**

- 论文报告 PI-Light 在高光、漫反射和真实场景泛化方面优于若干对比方法。
- 物理启发损失可以在较少数据和计算量下改善光照控制和泛化。
- 将光照分解为可控制的表示，有助于保持背景一致性并控制光照方向和强度。

**论文原文局限**

- VAE latent 与 RGB 并非严格空间对齐，latent mask 会产生颜色和模糊误差。
- 内在分解具有歧义，严重误差可能传递到最终重新打光结果。
- 当前前半球光照设定不能自由添加或修改后半球可见光源。
- 材质表示未显式覆盖 IOR、sheen、coat 等因素，可能把这些因素吸收到 metallic 等预测中。

**本地对应与结论**

- 本机有 `光影\IC-Light`、`光影\DiffusionRenderer` 和 `光影\LightCtrl` 等相关工程。
- 这些工程可以作为物理约束、光照分解和工程落地的参考，但没有证据表明本地已经复现 PI-Light。
- 对 LTX2.3/LightCtrl 工作的启发是：控制轨迹和光照参数需要单独记录，不能只依赖自然语言 Prompt。

### 6. LightPainter

**论文标题**

`LightPainter: Interactive Portrait Relighting with Freehand Scribble`

**文件**

`C:\Users\zhanghaotian\Desktop\工作\论文\LightPainter.pdf`

**核心方法**

- 通过用户在肖像图像上绘制的自由手 scribble 交互控制重打光效果。
- 使用 scribble simulation 生成不需要人工逐条标注的训练条件。
- 使用局部连接的 shading stripes 表示稀疏、局部和带方向的涂画输入。
- 采用两阶段重打光：先从 scribble 和几何条件补全合理的 shading map，再结合学习到的 albedo 生成最终外观。

**论文原文结论**

- 论文报告其系统可以把少量自由手输入转换为局部、可控且较自然的人像光照效果。
- 合成 scribble 与两阶段网络有助于提高对真实用户输入的泛化。
- 用户研究中，论文方法相较若干商业或已有工具获得更高偏好。

**本地对应与结论**

- 本机 `光影\LightCtrl` 有光照控制脚本、轨迹配置、模型和视频输出，但其输入方式是光照轨迹/参数，不是 LightPainter 的自由手 scribble。

- 这篇论文对交互设计的启发是：把复杂光照参数转成局部、可视化、低门槛的用户控制信号。

## 四、论文对当前技术路线的综合结论

### 1. 光影与重新打光

7 篇论文中，Diffusion Renderer、PI-Light、LightPainter 和 BodyReLux 都指向同一个演进方向：从单纯的图像亮度修改，逐步转向带几何、材质、光源、用户控制和时序一致性的条件生成。当前本地的 `IC-Light`、`DiffusionRenderer`、`FaceLight` 和 `LightCtrl` 分别覆盖了其中一部分，但不是这些论文方法的统一复现。

### 2. 身份和面部细节

InstaFace 关注身份、背景和面部属性控制；FLEX 关注皱纹、毛孔等高频微结构。两者共同说明：面部真实性不能只用整体图像相似度判断，还需要区分身份特征、局部结构、纹理细节和光照变化。这与当前评估器的身份、AU、面部纹理和人工复核方向相关，但属于技术参考关系。

### 3. 神经渲染与失效边界

RenderFormer 说明 Transformer 可以学习三角网格到图像的全局光照映射，但训练分布中的三角形数量、光源数量、相机范围和反射深度会直接决定泛化边界。这个结论可以迁移到当前评估器：评估结果应保留输入条件、模型版本、视频长度和控制参数，不能只保存一个综合分。

### 4. 对实验记录的要求

- 区分论文作者指标、本地复现指标和工程样例观察。
- 对每个重新打光结果记录光源轨迹、方向、强度、颜色、帧数和帧率。
- 对身份或纹理结果区分身份保持、局部细节、光照稳定和时序一致性。
- 对没有跨模型、跨生成批次验证的结果，不写成普适结论。
