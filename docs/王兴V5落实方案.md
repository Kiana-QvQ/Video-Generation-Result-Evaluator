## 1. 背景与问题诊断（必须保留的认知）

### 1.1 项目特化设定

- 数据集与模型均针对 **王兴**。
- 目标不是「是不是王兴」，而是：身份确认后，判断视频是 **真拍还是 AI**，并尽量给出 **管线相对质量序**。
- 表情特化目标应写成：

```text
这段 AU/landmark 时序，更像王兴真人神经驱动，
还是更像生成器驱动的王兴脸？
```

而不是：

```text
像不像王兴常做的那几类表情（微笑/愤怒/…画像距离）
```

### 1.2 V3 / V4 代码对齐

| 版本 | 代码位置 | 本质 |
|---|---|---|
| V3 | `wangxing_project/joint_au_pt_v3.py` | 全帧双尺度时序 + BiGRU + Attention + AU gate + modality dropout |
| V4.x | `outputs/历史归档/V4_实验_20260824/code/wangxing_project/joint_au_pt_v4*.py` | AU/landmark/Blendshape + 关系/时序头 + 后期 face-crop；**削弱或替换全帧主干**，仅作历史对照 |

#### 1.2.1 V3 冻结协议（实现必须遵守）

来自 `joint_au_pt_v3.py` 的关键常量（冻结时不得改结构）：

```text
V3_MODEL_TYPE = wangxing_temporal_au_video_v3
FRAME_DIM = 96
TEMPORAL_DIM = 6
TEMPORAL_HIDDEN = 128
VIDEO_DIM = TEMPORAL_HIDDEN * 2
AU_HIDDEN = 64
FUSION_HIDDEN = 128
FUSION_BOTTLENECK = 64
DEFAULT_MODALITY_DROPOUT = 0.10
DEFAULT_AUX_LOSS_WEIGHTS = {joint:0.80, video:0.10, au:0.10}
双尺度：SCALE_A / SCALE_B（来自 wangxing_dual_pt）
```

冻结检查清单：

```text
1. 推理只 load_state_dict，requires_grad=False
2. 阈值与 temperature 从 V3 checkpoint 读取，禁止在 25+25/32+32 上重搜
3. 训练 Drive/Rank 的脚本不得接受 --overwrite-v3 一类参数
4. 输出 y_v3 必须与「纯 V3 同视频推理」逐条一致（允许浮点误差 <1e-5 于 logit）
```

#### 1.2.2 V4.x 实测基线（V5 对照表）

```text
V4.1：25+25 Acc 78% / AI 84% / Real 72%；32+32 Acc 79.69%
V4.2：25+25 Acc 72% / AI 92% / Real 52%；32+32 Acc 59.38%
V4.3：25+25 Acc 78% / AI 92% / Real 64%；32+32 Acc 71.88%
V4.4：25+25 Acc 72% / AI 92% / Real 52%；32+32 Acc 68.75%
      ordering_satisfied=false；pairwise≈0.875
V3：  25+25 Acc 98% / AI 100% / Real 96%
```

V5 任一候选若决策翻转导致上述 V3 数字下降，直接否决。

#### 1.2.3 可复用缓存（避免重复抽特征）

优先复用，而不是重写抽取：

```text
wangxing_v42_expression_sequence.npz   # AU+landmark 序列（若存在）
wangxing_v4_blendshape.npz             # Blendshape 时序摘要
V4 transition cache                    # V5 DriveHead 仍可复用
LibreFace / AU CSV：resolve_au_csv_for_video()
网页 forensics cache：outputs/forensics/*_cache
V3 视频帧特征缓存（若 prepare 脚本已生成）
```

### 1.3 失败机制（五条）

1. **V3 不是纯表情模型**：可能学到压缩、构图、生成器域差；同域很强，但不能证明「只靠表情」。
2. **V4 删除过狠**：主信号只剩 AU/landmark/Blendshape/局部摘要，对「实拍 vs Seedance」以外的 AI 不够。
3. **统计摘要 ≠ 真时序**：缺 onset–apex–offset / 轨迹运动学。
4. **阈值偏 AI**：validation 如 0.37/0.44 拉高 AI 召回、打穿实拍召回——放大问题，不是根因。
5. **无排序监督**：只有实拍/Seedance，学不出 `真人>LoRA>Seedance>多图`。

### 1.4 本地已证实的表情误区

见 `docs/AI视频人工质量分档参考_20260819.md`：

- AI 表情证据均值可 **高于** 实拍；
- 多数 AI 落在实拍表情分区间；
- 「表情证据」适合 AI 内部相对参考，**不能**直接当真实拍摄概率。

### 1.5 论文对照（现象 → 方向）

| 现象 | 学术问题 | 代表方向 |
|---|---|---|
| 去掉全帧 RGB 时序后暴跌 | 时序不一致 / 域指纹 | FTCN、AltFreezing、LipForensics |
| 只留 AU/landmark 不够 | AU 是辅助生理约束，需挂强视觉主干 | AUNet、FADE、HAUTE |
| 统计摘要不够 | 轨迹 / 运动学 / 阶段建模 | landmark trajectory、kinematic inconsistency |
| 阈值偏 AI | 校准与代价敏感选阈 | temperature scaling、cost-sensitive |
| 学不出四档序 | 二分类无法学序 | RankSVM、RankNet、model attribution（FAME/CapST） |

**总判断：V4「表情生理」方向对，但做成了「替主干」；论文几乎都是「补主干」。**

## 2. V5 目标拆分（两个任务，禁止混成一个 logit）

| 目标 | 任务类型 | 主负责人 | 现数据能否完成 |
|---|---|---|---|
| A. 25+25 / 实拍召回 | real vs AI **二分类** | **冻结 V3** | 能 |
| B. 王兴真驱动 | 表情时序 **真驱动 vs 生成驱动** | DriveHead | 能做二档（真人 vs 已有 AI） |
| C. 四档管线序 | **排序 / 归因** | RankHead | **不能**在无成对数据时承诺 |

学术对应：

- Detection：FTCN / AUNet / LipForensics 族  
- Attribution / LTR：FAME、CapST、RankNet、RankSVM  

把 C 硬塞进「再训一个更复杂的二分类器」= V4 失败路径，V5 **禁止**。

## 3. 总体架构

### 3.1 三专家 + 展示层

```text
┌──────────────────────────────────────────────────────────┐
│ 专家 A：V3 真伪（冻结权重与决策阈值）                        │
│   输出：y_v3 ∈ {real, AI}，p_v3 ∈ [0,1]                   │
├──────────────────────────────────────────────────────────┤
│ 专家 B：DriveHead「王兴真人神经驱动」                        │
│   输出：p_drive = P(real-driven | AU/landmark/BS/crops)   │
│   约束：不回传更新 V3；不得单独作为上线决策                  │
├──────────────────────────────────────────────────────────┤
│ 专家 C：RankHead / Attributor（需成对/四元组数据）           │
│   输出：s_rank 或 管线类概率                                 │
│   约束：只在 AI 带内分档；不回传 V3                          │
├──────────────────────────────────────────────────────────┤
│ 展示层：词典序分段映射 → 对外一个分数                         │
│   内部仍保留 p_v3 / p_drive / s_rank / 各证据卡              │
└──────────────────────────────────────────────────────────┘
```

### 3.2 词典序保护（保 V3 指标的工程保证）

```text
所有「V3 判真人」的展示分  >  所有「V3 判 AI」的展示分
```

推荐分段（可微调边界，但不得破坏词典序）：

```text
V3 == real:
    score ∈ [0.75, 1.00]
    带内可用 p_v3、p_drive 微调（可选）

V3 == AI:
    score ∈ [0.00, 0.74]
    无 RankHead：用 p_drive（或现有 forensics）在带内映射
    有 RankHead：
        LoRA 带：     [0.50, 0.74]
        Seedance 带： [0.30, 0.49]
        多图带：      [0.00, 0.29]
```

说明：

- 这是 **工程级联**，不是某篇论文的 magically fusion 保证。  
- **禁止**用未约束的 `0.7*p_v3+0.2*p_expr+0.1*p_crop` 直接改写决策面（可作实验对照，不得作生产决策）。

### 3.3 与「70/20/10」的关系

| 说法 | V5 态度 |
|---|---|
| 多专家独立训练 + 推理融合 | 采纳（AVTENet/MSOC 思路） |
| 固定 70/20/10 一定排出四档 | **不采纳为保证** |
| 约束 w1≥0.6 的自由加权 | 仅作 **消融实验**，生产默认用词典序 |

## 4. 算法与论文落地映射

### 4.1 专家 A（保留 V3）

| 论文/技术 | 作用 | V5 动作 |
|---|---|---|
| FTCN（ICCV 2021） | 强调时间不一致 | 保留 V3 全帧时序价值，不砍 RGB |
| AltFreezing（CVPR 2023） | 防只啃空间或时间捷径 | **可选诊断**；不作为删主干理由 |
| V3 temperature | 概率校准 | 保留；不得借机改决策阈值乱搜 |

### 4.2 专家 B（DriveHead）

| 论文/技术 | 作用 | V5 落地程度要求 |
|---|---|---|
| AUNet | AU 关系 | 可用轻量 relation attention；完整 ART/TAP 为增强项 |
| FADE | AU 依赖图 | 可选增强，非 Phase1 必须 |
| HAUTE | AU × 上下文 | 理念对齐「补主干」；不单独上线 |
| Landmark trajectory（WACV） | 区域位移轨迹 | Phase1 应用差分轨迹，禁只用 mean/std |
| Kinematic inconsistency | 部位运动相关 | 指导特征设计 |
| Genuine vs fake emotion | 真假表情是动力学 | 标签用 real-driven vs gen-driven，不用七类 FER |
| LipForensics | 嘴部时空预训练 | Phase1 轻量 crop；Phase3 再追论文级预训练 |

### 4.3 专家 C（RankHead）

| 论文/技术 | 作用 | V5 落地 |
|---|---|---|
| RankNet / RankSVM | pairwise 相对序 | 主监督；复用并扩展 `train_wangxing_weighted_policy.py` |
| FAME / CapST | 生成器归因 | AI 子集可选多类 CE |
| Pairwise contrastive deepfake | 成对相对学习 | 同设定四元组上使用 |

### 4.4 本地论文落地现状（避免误报「已复现」）

| 方向 | 现状 |
|---|---|
| AUNet | V4 有轻量 relation；**未**完整 ART/TAP |
| LipForensics | 有 landmark/crop；**未**嘴部预训练 backbone |
| FTCN/TT | V4 有轻量；**未**论文级协议 |
| FAME/CapST/AltFreezing/FADE/HAUTE | **未实现** |
| V5 级联 / score_band | 已实现候选；正式网页仍由 feature flag/验收决定是否启用 |
| 网页 pairwise 骨架 | **已有**；小样本，ordering 常不满足 |

## 5. 专家 B：DriveHead 规格（真驱动）

### 5.1 定义

```text
p_drive = P(时序由王兴真人神经驱动 | 特征)
正例：王兴真人视频的 AU/landmark/Blendshape/局部序列
负例：同人 Seedance 及已有 AI 王兴序列
```

### 5.2 输入特征（Phase1 最小集）

必须：

- AU 序列 + 一阶/二阶差分（速度、加速度）
- Landmark 分区轨迹差分（眼、眉、嘴、下颌）
- Blendshape 时序（若缓存可得）

可选：

- 眼/嘴/眉/下脸 crop 的浅时序（灰度/边缘/残差或小 GRU）
- AU 质量、脸检测 coverage（作 gate，不作身份抬分）

禁止作为 **主监督**：

- 六类表情 CE  
- 「离微笑/愤怒画像距离」直接当 p_drive  

画像仅可用于：coverage、可解释「最接近表情类」、质量降权。

#### 5.2.1 序列采样协议（建议与 V4.2 对齐以便复用缓存）

```text
目标帧数 T：与 SEQUENCE_MAX_FRAMES 一致（见 joint_au_pt_v42）
采样：均匀时间采样；缺帧边缘 pad + mask
每帧：AU（LibreFace）+ landmark 归一化 +（可选）Blendshape 52
差分：v_t=x_t-x_{t-1}，a_t=v_t-v_{t-1}；输入 concat(x,v,a) 或 Conv1d 学差分
```

#### 5.2.2 区域轨迹（WACV trajectory 可编码版）

```text
区域：left_eye, right_eye, brows, nose, mouth, jaw
质心位移 d_r(t)；可选减鼻尖质心抑头动
可选耦合：滑窗 corr(眉-眼)、corr(嘴-颌)
```

#### 5.2.3 Onset–Apex–Offset 弱标注（可选）

```text
E(t)=Σ w_k AU_k(t) → 启发式切 onset/apex/offset
可对 apex 邻域加权；不得用三段统计替代整段序列主干
```

### 5.3 网络（Phase1 建议）

```text
AU Rel-Attn（轻量）
  + Temporal Conv 或 小窗口 Transformer
  + Landmark GRU
  +（可选）crop 辅助头
→ 共享表征 → sigmoid → p_drive
```

可参考 V4.2 尺寸（可下调）：`AU_REL_HIDDEN=32, TEMPORAL_HIDDEN=64, LOCAL_HIDDEN=48, FUSION_HIDDEN=96`。

约束：

- **禁止**只拼 clip-level mean/std 冒充时序；
- summary 分支仅辅助；参数量优先小模型；小数据忌堆深 Transformer；
- 与 V4.2 关键区别：监督是 `y_drive`，推理不替代 V3。

### 5.4 损失（公式级）

```text
Focal: L_focal = -α_t (1-p_t)^γ log(p_t)    建议 γ=2.0
L_smooth = mean_t ||h_t-h_{t+1}||_1
L_shuffle = hinge(同视频打乱后驱动分应更低)
难负例：时间打乱 / AU 区置换 / 嘴眼异步（目标偏 0）
L_drive = L_focal + 0.2*L_temporal + 0.3*L_hardneg + 0.1*L_aux
```

可选后续：真人序列自监督（下一窗预测）→ 冻特征再接驱动头。

### 5.5 Gate

```text
q = min(au_coverage, face_detection_rate, landmark_stability)
g = 0 if q < 0.4 else (q-0.4)/0.6
p_drive_eff = g*p_drive + (1-g)*0.5
质量差：drive_status=unavailable
```

Gate 只作用于辅助支路，禁止反过来 gate 掉 V3。

### 5.6 训练超参（Phase1 默认）

```text
epochs 60–100；batch 8–16；AdamW；lr 1e-3~3e-4；wd 1e-4
grad_clip 1.0；sequence dropout 0.1；固定 seed 写入 metrics
早停：val AUC/NLL；监控实拍侧 p_drive 勿整体塌到 0
禁止：只按 AI 召回选 checkpoint
```

## 6. 专家 C：RankHead 规格（四档序）

### 6.1 目标序

```text
真人 > LTX2.3+自有 LoRA > Seedance 2.0 > LTX2.3+多图参考
```

代码标签约定（与现有一致）：

```text
ORDER = ("real", "lora", "seedance", "multiref")
RANK  = {real:3, lora:2, seedance:1, multiref:0}
```

### 6.2 数据要求（硬条件）

当前 ppt_video ≈ 8 条 → **禁止**单独深训。

最低可行：

```text
至少几十组 query（目标 30–100+）
每组尽量：同一身份（王兴）、同一 Prompt、同一表情脚本
          相近机位/背景/光照/时长
每组含：真人 | LTX+LoRA | Seedance | LTX+多图（能缺则记 missing，不进完整四元评价）
按身份/场景/表情/生成批次分组，防泄漏
不得进入 25+25、32+32 最终测试集
```

### 6.3 特征

```text
冻结 V3：p_v3 / embedding（只读）
+ p_drive
+ 现有 forensics：facial-motion、texture、frequency、temporal naturalness 等
+ face-crop residual / source signature（若有）
```

小样本优先：**线性 / 浅层 pairwise**，再考虑浅时序归因头。

### 6.4 损失（公式级）

RankNet 风格 pairwise logistic（与现有 `train_wangxing_weighted_policy.py` 一致）：

```text
对所有 RANK(i)>RANK(j) 的样本对：
  Δ = x_i - x_j
  L_pair = -[ y log σ(w·Δ+b) + (1-y) log(1-σ(w·Δ+b)) ]
  训练时同时加入 -Δ 与标签翻转以对称
```

RankSVM hinge（小样本备选）：

```text
L_hinge = max(0, margin - (s_i - s_j))    margin 默认 0.1~0.5
```

可选归因头（仅 AI 子集三分类）：

```text
L_attr = CE(y ∈ {lora, seedance, multiref})
L_rank_total = L_pair + λ_attr * L_attr     λ_attr 初值 0.3
```

**禁止** `L_rank` 回传更新 V3。

### 6.4.1 Rank 特征向量（建议维度，可裁剪）

复用并扩展 `RANK_FEATURE_NAMES`：

```text
identity, expression, direction,
real_domain_fit_0_1, ai_domain_inverse_0_1,
temporal_naturalness_0_1, texture_stability_0_1, frequency_naturalness_0_1,
p_v3, p_drive, p_drive_eff,
au_velocity_energy, landmark_jitter, blendshape_entropy（若可算）
```

标准化：训练集 mean/std；推理用同一 scaler。

### 6.4.2 Rank 训练超参

```text
优先：sklearn LogisticRegression(C=0.5, class_weight=balanced) 或 LinearSVC
样本<200 对：禁止深度排序网
样本≥500 对：可试 1–2 层 MLP，仍建议 L2 强正则
交叉验证：按 query/组别 GroupKFold，禁止随机打乱泄漏
```

### 6.5 验收指标

```text
class_means 满足 ORDER 严格递减
pairwise_ordering_rate（按 RANK 应大于的对）尽可能高
上线要求：ordering_satisfied = true
  （与现 train_wangxing_weighted_policy 定义对齐：类序成立且 pairwise 全对，或项目另行规定的阈值）
```

现有入口：`scripts/web_forensics/train_wangxing_weighted_policy.py`  
→ V5 应扩展为正式 RankHead 训练，并输出 `rank_model` 到 policy。

## 7. 展示分与决策面

### 7.1 决策比特（生产）

```text
y_decision = y_v3
threshold_decision = V3 validation 阈值（冻结）
```

旁路 **不得** 把「V3=real」改成 AI，也不得把「V3=AI」改成 real（除非未来单独开「人工复核覆盖」开关，默认关闭）。

### 7.2 展示分伪代码与映射公式

```text
function cascade_score(p_v3, y_v3, p_drive, s_rank=None, band_cfg=DEFAULT):
    if y_v3 == real:
        return map_real_band(p_v3, p_drive, band_cfg.real)   # [0.75,1]
    else:
        if s_rank is available and rank_policy_enabled:
            return map_ai_band_by_rank(s_rank, band_cfg)
        else:
            return map_ai_band_by_drive(p_drive, band_cfg.ai)
```

推荐映射（单调、可测）：

```text
map_real_band:
  u = 0.85 * p_v3 + 0.15 * p_drive_eff
  score = 0.75 + 0.25 * u

map_ai_band_by_drive（无排序数据）:
  score = 0.00 + 0.74 * p_drive_eff

map_ai_band_by_rank（有排序且 ordering_satisfied）:
  先得到 band ∈ {lora, seedance, multiref}
  再在对应区间内用 s_rank 分位数插值：
    lora:     [0.50, 0.74]
    seedance: [0.30, 0.49]
    multiref: [0.00, 0.29]
```

不变量测试（单元测试必须写）：

```text
∀ real 样本 score > 0.75-eps
∀ AI 样本 score < 0.75
∀ 同阈值下 y_display_decision == y_v3
```

### 7.3 对内输出字段（网页/PT 统一）

```text
p_v3
y_v3
p_drive
s_rank（可空）
score_display
score_band ∈ {real, lora, seedance, multiref, ai_unspecified}
coverage / quality flags
identity_*（仅身份卡，不进真实性主证据）
expression_profile_*（仅解释，不进 p_drive 主损失）
```

## 30. 技术附录 K：常见失败模式排障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 接 Drive 后 Acc 下降 | 误用自由融合改决策 | 改回 y_v3 词典序 |
| p_drive 真人很低 | 难负例过强 / 标签反了 / 阈值偏 AI | 查标签；降 λ_hard；看分布 |
| p_drive AI 虚高 | 学成画像相似 | 加 hardneg；去掉画像主损失 |
| ordering 好但测试崩 | 8 条过拟合 | 扩数据；改线性模型 |
| 网页分与 PT 不一致 | policy/模型路径不同 | 统一 trace 字段 |
| unavailable 过多 | AU/脸失败 | 修检测；降 q_min 仅作展示勿改决策 |
