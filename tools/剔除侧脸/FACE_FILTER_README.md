# 人脸完整度筛选工具

这个工具使用人脸特征模型逐帧检查视频，删除人脸不完整或侧脸过明显的画面。

## 功能

- 检查画面中是否检测到人脸。
- 检查人脸检测可信度。
- 检查五个关键点是否都在画面内。
- 检查人脸大小和靠近画面边缘的程度。
- 检查是否存在明显侧脸。
- 检查人脸特征是否有效。

不符合条件的画面会被删除，并记录删除原因。

## 输入和输出

输入为一个视频文件。

输出包括：

- 删除不合格画面后的视频。
- 逐帧检查报告。

报告会记录原始帧号、时间、人脸质量分数、是否保留以及删除原因。

注意：输出视频不保留声音，删除画面后视频时长会缩短。输出视频适合后续人脸完整度或动作单元分析，不适合要求时间连续的分析。

## 使用方法

在项目根目录执行：

```powershell
python -m pip install -r tools\face_filter_requirements.txt

python tools\filter_incomplete_face_frames.py `
  --input 输入视频.mp4 `
  --output 筛选后视频.mp4 `
  --model-root model_cache\insightface `
  --device cpu
```

第一次运行可能会自动下载模型。离线使用时，请提前把模型文件放到 `--model-root` 指定的目录。

## 默认条件

| 条件 | 默认值 | 说明 |
| --- | ---: | --- |
| 人脸检测可信度 | 0.60 | 人脸检测结果的最低可信度 |
| 关键点覆盖率 | 1.00 | 五个关键点必须全部在画面内 |
| 人脸面积比例 | 0.01 | 人脸至少占画面的百分之一 |
| 边缘距离比例 | 0.01 | 人脸不能过于靠近画面边缘 |
| 对称分数 | 0.75 | 低于此值时视为侧脸明显 |
| 双眼间距比例 | 0.30 | 双眼距离至少占人脸宽度的百分之三十 |
| 综合质量分数 | 0.60 | 画面保留所需的最低分数 |

可以按需要放宽侧脸条件：

```powershell
--min-symmetry 0.60 --min-quality 0.50
```

默认使用较准确的人脸模型，支持使用中央处理器运行，不要求显卡。
