# Authenticity Contract Experiments

This directory is isolated from the production Wang Xing runtime.

Baseline date: 2026-09-07

Rules:

- Do not modify production inference, models, feature profiles, or runtime flags.
- Treat `data/test/single_video`, `data/test/wangxing_32x32`, and their
  source manifests as final evaluation-only assets.
- Write all candidate models, extracted features, calibration files, and
  reports under this directory or its `artifacts/` subdirectory.
- A candidate may replace the baseline only after it passes the frozen
  acceptance report generated from the baseline snapshot.

The first artifact is `baseline_snapshot.json`, generated by
`snapshot_baseline.ps1`.
